# Topic Selection & Evaluation

> Note selection is where Xiaohongshu performance is won or lost.
> A decent package on a sharp note angle will outperform a polished package built on a vague topic.

---

## The One Rule

**A note angle is worth writing about if and only if you can answer this:** "Why would someone save or share this note today instead of scrolling past it?"

If the answer is "because it's well written" — that's not enough.
If the answer is "because it names a problem, payoff, or judgment they want immediately" — proceed.

## Evaluation Model: 5 Dimensions

### 1. Heat (权重 20%)

How visible is this topic right now?

### 2. Audience Fit (权重 25%)

How naturally does this fit the client's readers?

### 3. Angle Value (权重 25%)

Can you package this as a clear note angle instead of a generic broad theme?

### 4. Engagement Potential (权重 15%)

Will this trigger saves, comments, or shares?

### 5. Packaging Potential (权重 15%)

Can this become a strong title + hook + visual package?

## Scoring Formula

```text
Final Score = (Heat × 0.20) + (Fit × 0.25) + (Angle × 0.25) + (Engagement × 0.15) + (Packaging × 0.15)
```

## Output: 10 Note Angles

Each angle must include:

- Draft title
- Final score
- Dimension breakdown
- Save/share prediction
- Recommended framework
- Dedup flag vs. `history.yaml`
- Core tension draft

## Sorting Rules

1. Sort by final score, descending
2. Tie-breaker 1: Higher Packaging Potential wins
3. Tie-breaker 2: Higher Audience Fit wins
4. Angles flagged `近期已覆盖` go to bottom regardless of score
