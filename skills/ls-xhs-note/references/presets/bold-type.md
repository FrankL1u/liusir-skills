# Bold Type Style

Big-type statement aesthetic with oversized words, minimal support graphics, and aggressive first-screen impact.

## Best for

- hard-hitting covers
- strong opinions
- one-line judgments
- high-contrast opening claims

## Visual cues

- giant headline as the dominant visual object
- minimal icon support
- one strong accent color over a clean background
- wide spacing around the main statement

## Typography cues

- oversized heavy type
- compressed or blocky headline feel
- secondary text kept minimal

## Do

- let one sentence dominate the entire frame
- keep support visuals secondary
- make the first read instantaneous

## Do not

- squeeze in too many sub-points
- turn it into a detailed knowledge card
- weaken the impact with decorative clutter
