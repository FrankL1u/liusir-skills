# Tech Blueprint Style

Structured technical infographic aesthetic with grid lines, panels, callouts, and product-spec clarity.

## Best for

- system breakdowns
- layered frameworks
- production workflows
- knowledge-dense technical explainers

## Visual cues

- light grid or drafting-paper background
- module frames, callout lines, and labeled panels
- cool neutral palette with one blue accent family
- component stacking and schematic composition

## Typography cues

- clean technical headline
- strong label hierarchy
- caption-like annotations and module names

## Do

- keep hierarchy extremely clear
- use frames, arrows, and labels to explain structure
- make the page feel engineered rather than decorative

## Do not

- add cute lifestyle stickers
- use soft watercolor treatment
- let ornament overwhelm the diagram logic
